# 用户指南

## 放置与移动

打开右下角“元件”面板，可搜索型号、名称或用途，也可按功能筛选。选择后移到孔位预览，点击确认；Esc 取消。ESP32-S3 可放在单块面包板上，也可从有右侧相邻板的 I/J 列跨板放置。页面标注的是当前模型，实物不同批次的尺寸与针序仍需核对。

已放置的板件单击只选中。**按住板身并拖动**才会移动，松手后落位；连接该模块的跳线会随之移动。同类外设可以重复添加，编号为 #2、#3 等；主板目前只有一份。

顶部“面包板”按钮添加新板；板头 × 移除对应板。有相关模块或跳线时会提示受影响内容。误操作可在断电状态下撤销。

## 接线与选线

点击起点孔，再点终点孔。相同面包板、同一行的 A–E 导通，F–J 另成一组，两侧之间不自动相连；不同面包板需要跳线。

当前模型将每一列电源轨视为整列连通。实物电源轨可能分段，不要直接按屏幕颜色推断实物通断。

同一网络使用同色，实心色块表示接点或针脚。点击线段可选中跳线，按 Delete 删除；右侧列表也可选线或点击“拆”。处于接线状态时，孔位优先接收点击；不想继续接线可按 Esc。

“隐藏连线 / 显示连线”和“隐藏硬件 / 显示硬件”表示点击后执行的动作。隐藏只影响显示，不会删除模块或线路。针脚文字显示在连线上方。

## 通电与测试

按 Enter 或点击“模拟通电”。顶部显示“通电中 · 布线已锁定”，此时禁止布线、移动、增删和撤销，仍可查看详情、缩放和测试。

右侧按硬件实例显示测试入口，点击对应设备查看检查结果和控制项。测试 GPIO 以针脚说明中的练习接点为准；并非任意 GPIO 接好都能通过。GPIO 的实际用途仍由你烧录的程序决定。

再次按 Enter 或点击“断电”恢复编辑。通断电不改变画布布局。若看到短接提示，先断电，再修改提示对应的网络。

常见模拟效果：LED 亮灭、按钮输入、电位器/光照 ADC、环境读数、人体感应、距离、舵机角度、OLED 状态和音频播放。这些都是预设模型，不读取真实传感器或麦克风。

## 详情、缩放和快捷键

右键板件或针脚打开详情；选中板件后，也可通过画布底部的“针脚详情”进入。完成后关闭弹窗。

| 操作 | 作用 |
| --- | --- |
| Enter / Return | 通电或断电；输入框、弹窗等状态下不触发全局切换 |
| Esc | 取消当前选择、接线或放置；弹窗可按 Esc 关闭 |
| Delete / Backspace | 删除选中的跳线或外设；先断电 |
| ⌘Z / Ctrl+Z | 撤销编辑；先断电，刷新后历史清空 |
| 画布左下角 − / + | 缩小 / 放大 |
| 点击百分比 | 回到 100%，按画布高度适配 |
| 画布内双指缩放或 Ctrl+滚轮 | 缩放画布；真实设备手势仍可能受浏览器影响 |
| 普通滚动 | 在画布内上下、左右查看多块板 |

目前 Tab / Shift+Tab 已禁用。针脚详情提供文字说明，但不能视为完整键盘或屏幕阅读器支持。

## 常见问题

**没有声音**：先检查线路是否通过，点击“试听浏览器声音”，再检查当前标签页静音、系统音量和输出设备。浏览器可能要求先由用户点击启动音频。

**测试入口不见了**：确认模块已落位，尚在预览中的硬件不会列为已放置设备；再检查对应设备的测试入口。仅添加主板时没有外设测试项。

**刷新后不能编辑**：工作台恢复了此前的通电状态，先断电。

**缓存没有恢复**：确认使用相同域名和浏览器。隐私模式、存储权限或清理站点数据可能导致缓存丢失。网站暂无导入导出与跨设备同步。

**窄屏操作拥挤**：优先使用桌面浏览器；窄屏侧栏采用浮层，可能占用部分画布视野。
